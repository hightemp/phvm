# phvm 1.0.6

This patch adds a dedicated dependency recipe for building older PHP versions on systems whose default OpenSSL is newer than those PHP branches support.

- PHP versions below 7.1 select private OpenSSL 1.0.2u and curl 8.5.0. OpenSSL is built first, and curl is built against that private prefix.
- PHP 7.1 through 8.0 retain the OpenSSL 1.1.x dependency recipe for compatibility with systems using OpenSSL 3.
- Installation progress reports which OpenSSL branch will be built automatically.

These are source-build compatibility changes; the dependency recipe does not by itself certify every legacy PHP version or platform.
